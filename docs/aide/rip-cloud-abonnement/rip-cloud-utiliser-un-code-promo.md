Un code promo ou partenaire peut réduire le prix ou offrir des mois.
Il se saisit à la souscription, dans un champ unique.

## Avant de commencer

- Ayez votre code sous la main.
- Le code est facultatif.

## Étapes

1. Ouvrez **Abonnement**, puis **Voir les offres**, choisissez l'offre et cliquez sur **Choisir**.
2. Dans la rubrique **Code promo ou partenaire**, saisissez le code dans le champ **Code (facultatif)**.
3. Lisez la ligne qui s'affiche dessous : le code est vérifié aussitôt et ses conditions apparaissent (par exemple « 2 mois offerts » ou un pourcentage de remise).
4. Continuez la souscription. Voir [Souscrire une offre payante](rip-cloud-souscrire-une-offre.md).

## Bon à savoir

- Un code refusé le signale tout de suite : corrigez-le ou supprimez-le pour continuer.
- Un seul champ est prévu : saisissez un code à la fois, code promo ou code partenaire.
- En cas de doute sur un code, écrivez à contact@e-ko.rip.
