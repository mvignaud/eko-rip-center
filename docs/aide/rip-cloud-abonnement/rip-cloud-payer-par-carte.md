Le paiement par carte se fait dans la page, sans la quitter.
La plate-forme ne voit jamais le numéro de votre carte.

## Avant de commencer

- Vous venez de cliquer sur **Continuer vers le paiement** : voir [Souscrire une offre payante](rip-cloud-souscrire-une-offre.md).
- Gardez votre carte et, si votre banque le demande, votre application ou votre téléphone pour confirmer.

## Étapes

1. Sur la page **Paiement**, vérifiez le rappel de l'offre et de la périodicité.
2. Cliquez sur **Carte bancaire** si cet onglet n'est pas déjà actif.
3. Saisissez la carte dans le champ sécurisé de la rubrique **Carte bancaire**.
4. Cliquez sur **Enregistrer la carte et valider**.
5. Si votre banque demande une confirmation (3-D Secure), elle s'affiche dans une fenêtre au-dessus de la page : validez-la.

La page confirme alors que l'abonnement est actif.

## Bon à savoir

- La carte est saisie dans un champ sécurisé du prestataire de paiement, pas sur la plate-forme.
- Pour l'offre Atelier en première souscription, la carte est seulement vérifiée pendant l'essai : aucun débit avant la fin des 30 jours. Voir [Profiter des 30 jours d'essai de l'offre Atelier](rip-cloud-essai-atelier.md).
- Le paiement par carte a besoin de JavaScript dans le navigateur ; sinon, choisissez le prélèvement SEPA.
- Pour changer de carte plus tard, cliquez sur **Changer de moyen de paiement** dans **Abonnement**. Voir [Changer d'offre, de paiement ou résilier](rip-cloud-changer-ou-resilier.md).
- Si le paiement est refusé, voir [Que faire en cas de paiement refusé](rip-cloud-paiement-refuse.md).
