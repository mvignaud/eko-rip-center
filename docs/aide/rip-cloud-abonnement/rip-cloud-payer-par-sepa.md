Le prélèvement SEPA se règle entièrement dans la page : mandat, code par SMS, signature.
Le mandat est créé au nom de SAS GOLDEN PRINT.

## Avant de commencer

- Vous venez de cliquer sur **Continuer vers le paiement** : voir [Souscrire une offre payante](rip-cloud-souscrire-une-offre.md).
- Ayez l'IBAN, le nom du titulaire et un téléphone mobile qui reçoit les SMS.
- Le mandat vaut pour l'entreprise renseignée à la souscription. Si elle change avant la signature, créez un nouveau mandat.

## Étapes

1. Sur la page **Paiement**, cliquez sur **Prélèvement SEPA**.
2. Saisissez l'**IBAN**, le **BIC** (facultatif), le prénom et le nom du titulaire, le téléphone mobile (pour le code SMS) et l'adresse.
3. Cliquez sur **Créer le mandat**. Le mandat s'affiche dans la page.
4. Lisez-le. Vous pouvez l'ouvrir en PDF avec **Ouvrir le mandat (PDF)**.
5. Cliquez sur **Recevoir le code par SMS**. Le code peut mettre une minute à arriver.
6. Saisissez le **Code reçu par SMS**, puis le **Nom et prénom du signataire**, tapés comme signature.
7. Cochez l'autorisation de prélèvement, puis cliquez sur **Signer le mandat**.

La page indique que le mandat est signé et que l'abonnement est actif.

## Bon à savoir

- Le mandat signé reste téléchargeable depuis la page **Abonnement**.
- Pour utiliser un autre compte bancaire avant la signature, cliquez sur **Utiliser un autre compte**.
- Si le code n'arrive pas, vérifiez le numéro de téléphone saisi, attendez une minute, puis redemandez-le.
- Un e-mail confirme la signature du mandat.
- Pour changer de compte bancaire plus tard, utilisez **Changer de moyen de paiement**. Voir [Changer d'offre, de paiement ou résilier](rip-cloud-changer-ou-resilier.md).
