L'accès à distance est suspendu quand l'offre est dépassée depuis plus de 14 jours.
Le travail à l'atelier n'a pas été interrompu.

## Avant de commencer

- Se connecter au portail avec le compte propriétaire.
- Un e-mail vous a prévenu du dépassement.

## Étapes

1. Ouvrez **Abonnement**.
2. Consultez les machines et sites comptés.
3. Souscrivez une offre adaptée avec **Voir les offres**.
4. Ou retirez les machines ou les sites en trop.

## Bon à savoir

- L'accès revient dès la régularisation.
- Une page explicative s'affiche dans le navigateur quand l'accès est suspendu ; les apps reçoivent la réponse « offre dépassée ».
- L'utilisation à l'atelier n'est jamais touchée : le serveur continue d'imprimer et de découper.
