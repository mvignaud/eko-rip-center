L'application affiche une erreur de connexion au serveur. Dans la plupart des cas, l'adresse locale est utilisée hors de l'atelier.

## Avant de commencer

Vous avez l'adresse du serveur, la même que dans les clients de bureau.

## Étapes

1. Si vous utilisez l'adresse locale, vérifiez que le téléphone est sur le Wi-Fi de l'atelier.
2. Vérifiez l'adresse saisie, sans espace : `http://<adresse-du-serveur>:8640`.
3. Hors de l'atelier, touchez **Se connecter au cloud** : l'adresse locale n'est joignable que sur place.
4. Si le problème persiste, vérifiez que le serveur tourne (voir [Le client ne trouve pas le serveur](rip-client-ne-trouve-pas-le-serveur.md)).

## Bon à savoir

- Un compte refusé est un autre problème : voir [Connexion refusée](rip-connexion-refusee.md).
- Sans cloud, il faut un VPN pour atteindre le serveur de l'extérieur.
