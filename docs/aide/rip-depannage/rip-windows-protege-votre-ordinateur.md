À l'ouverture de l'installateur Windows, un écran bleu « Windows a protégé votre ordinateur » bloque le lancement. Le client Windows n'est pas encore signé : une autorisation suffit, une seule fois par poste.

## Avant de commencer

Vous avez téléchargé l'installateur depuis la page officielle https://e-ko.rip/telecharger/#windows. Vous pouvez comparer son empreinte SHA-256 avec celle indiquée sur la page.

## Étapes

1. Sur l'écran d'avertissement, cliquez **Informations complémentaires**.
2. Cliquez **Exécuter quand même**.
3. Suivez l'assistant d'installation.

## Bon à savoir

- Le client Mac, lui, est signé et vérifié par Apple : il s'ouvre sans avertissement.
- Le client s'installe pour l'utilisateur courant, sans droits d'administrateur.
