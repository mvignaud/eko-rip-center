Dans la liste **Vos sites**, un site hors ligne n'est pas joignable : le serveur de l'atelier n'est pas relié à la plate-forme.

## Avant de commencer

Vous avez accès au serveur sur place, ou quelqu'un de l'atelier peut le vérifier.

## Étapes

1. Vérifiez sur place que le serveur RIP est allumé.
2. Vérifiez qu'il a accès à Internet.
3. Rouvrez l'application et touchez de nouveau le site.

## Bon à savoir

- Quand le site revient en ligne, une notification de la plate-forme vous prévient si les notifications du compte sont activées.
- Le détail du diagnostic côté plate-forme est dans l'article sur les sites hors ligne.
