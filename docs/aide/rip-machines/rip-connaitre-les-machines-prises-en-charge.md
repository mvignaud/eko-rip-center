Chaque machine du catalogue a son article. Cet article les range par famille et indique quoi faire pour un modèle qui n'y figure pas.

## Avant de commencer

Rien de particulier : cet article est une référence.

## Étapes

1. Repérez votre machine dans ce tableau, puis ouvrez son article.

   | Famille | Machine | Le RIP pilote |
   |---|---|---|
   | **Imprimantes** | [Epson SureColor SC-S80600](rip-brancher-epson-sc-s80600.md) | l'impression (pilote direct) |
   | | [Roland VersaCAMM VP-300 / VP-540](rip-brancher-roland-versacamm.md) | la découpe (imprimante-découpeuse) |
   | **Plotters de découpe** | [Mutoh Kona 1650](rip-brancher-mutoh-kona-1650.md) | la découpe, avec repérage |
   | | [Graphtec FC7000](rip-brancher-graphtec-fc7000.md) | la découpe |
   | **Tables de découpe** | [aucune pour l'instant](rip-preparer-une-planche-pour-une-table-de-decoupe.md) | |

2. Pour déclarer la machine, suivez [Ajouter une machine au RIP](rip-ajouter-une-machine.md).
3. Pour un modèle absent de la liste, essayez d'abord la connexion **Dossier** (le RIP dépose les fichiers que le logiciel de la machine surveille) ou **IPP** : voir [Choisir la connexion d'une machine](rip-choisir-la-connexion-d-une-machine.md).
4. Pour demander la prise en charge d'un modèle, écrivez à [contact@e-ko.rip](mailto:contact@e-ko.rip) avec la marque, le modèle et la façon dont il est branché.

## Bon à savoir

- Chaque nouvelle machine prise en charge par le RIP reçoit son article dans la bonne famille.
- Les modèles du catalogue sont : Epson SC-S80600, Mutoh Kona, Graphtec FC7000 et Roland VersaCAMM VP.
- Pour ce qui n'est pas encore pris en charge sur ces machines, voir [Connaître les limites actuelles du RIP](rip-connaitre-les-limites-actuelles-du-rip.md).
