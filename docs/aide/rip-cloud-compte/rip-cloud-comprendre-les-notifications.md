En plus des e-mails, la plate-forme notifie les mêmes événements dans votre navigateur et dans les apps.
Cet article explique ce qui est notifié et où.

## Avant de commencer

- Les notifications suivent la case **Recevoir les alertes** de **Mon compte**.
- Elles concernent les propriétaires et les administrateurs du site.

## Étapes

1. Repérez les événements notifiés :
   - **site hors ligne**, après 15 minutes sans réponse du serveur ;
   - **site de retour en ligne**, seulement si l'alerte « hors ligne » est partie ;
   - **nouvelle app connectée**.
2. Choisissez où les recevoir :
   - **dans le navigateur** : voir [Activer les notifications du cloud](rip-cloud-activer-les-notifications.md) ;
   - **dans les apps Mac, Linux, Windows et mobile** : acceptez l'autorisation d'afficher des notifications, demandée juste après la première connexion au cloud.
3. Pour arrêter sur un navigateur, voir [Arrêter les notifications d'un navigateur](rip-cloud-retirer-un-navigateur.md).

## Bon à savoir

- La notification **nouvelle app connectée** est toujours envoyée, même si **Recevoir les alertes** est décochée : c'est une mesure de sécurité.
- Les notifications partent même quand l'envoi d'e-mails n'est pas réglé.
- Les apps de bureau (Mac, Linux, Windows) consultent le journal de la plate-forme chaque minute. Ce journal garde les notifications 30 jours ; au premier lancement, une app ne rattrape pas les anciennes.
- Sur mobile, la notification arrive même app fermée. Le téléphone est rattaché à l'accès de l'app : il disparaît quand l'app est déconnectée, quand l'accès est révoqué dans **Mon compte** ou quand le compte est supprimé. Un même appareil reconnecté ne notifie qu'une fois.
- Dans le navigateur, les notifications arrivent même quand la page du portail est fermée, tant que le navigateur est lancé. Dix navigateurs au plus peuvent être inscrits par compte.
- Si l'autorisation a été refusée dans le navigateur ou dans l'app, rétablissez-la dans les réglages du navigateur, du système ou du téléphone, puis rechargez la page.
- Si les notifications du téléphone n'arrivent pas, voir [Je ne reçois pas les notifications de l'application mobile](../rip-depannage/rip-notifications-mobile-absentes.md).
