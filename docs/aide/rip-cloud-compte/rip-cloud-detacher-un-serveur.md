Détacher un serveur arrête son accès à distance.
Le serveur et ses données ne sont pas touchés.

## Avant de commencer

- Seul le propriétaire du site peut le retirer depuis le portail.
- Pour rétablir l'accès plus tard, il faudra relier de nouveau le serveur avec un nouveau code.

## Étapes

Depuis le serveur :

1. Ouvrez **Système › Cloud E-KO RIP**.
2. Cliquez sur **Détacher de la plate-forme**.
3. Confirmez.

   ![Section Cloud E-KO RIP avec l'état Connecté et le bouton Détacher de la plate-forme](../images/cloud-serveur-connecte.png)

Depuis le portail :

1. Ouvrez **Mes sites**.
2. Cliquez sur **Retirer** à côté du site.
3. Confirmez.

![Liste Mes sites avec le bouton Retirer à côté de chaque site](../images/cloud-mes-sites.png)

## Bon à savoir

- L'accès à distance s'arrête aussitôt.
- Le détachement depuis le serveur se fait uniquement depuis l'atelier, jamais par le cloud.
- Le serveur oublie sa clé : il faudra un nouveau code pour rétablir l'accès. Voir [Relier un serveur RIP au cloud](../rip-cloud-premiers-pas/rip-cloud-relier-un-serveur.md).
- Si vous retirez le site depuis le portail, le serveur reste utilisable sur place.
- Après un retrait, les sauvegardes du site sont supprimées 90 jours après la dernière.
