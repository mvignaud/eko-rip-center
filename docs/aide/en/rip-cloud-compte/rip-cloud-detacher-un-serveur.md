Unlinking a server stops its remote access.
The server and its data are not touched.

## Before you start

- Only the site's owner can remove it from the portal.
- To restore access later, you will need to link the server again with a new code.

## Steps

From the server:

1. Open **System › E-KO RIP Cloud** (*Système › Cloud E-KO RIP*).
2. Click **Unlink from the platform** (*Détacher de la plate-forme*).
3. Confirm.

   ![E-KO RIP Cloud section with the Connected status and the Unlink from the platform button](../../images/cloud-serveur-connecte.png)

From the portal:

1. Open **My sites** (*Mes sites*).
2. Click **Remove** (*Retirer*) next to the site.
3. Confirm.

![My sites list with the Remove button next to each site](../../images/cloud-mes-sites.png)

## Good to know

- Remote access stops immediately.
- Unlinking from the server is done only from the workshop, never through the cloud.
- The server forgets its key: you will need a new code to restore access. See [Link a RIP server to the cloud](../rip-cloud-premiers-pas/rip-cloud-relier-un-serveur.md).
- If you remove the site from the portal, the server stays usable on site.
- After a removal, the site's backups are deleted 90 days after the last one.
