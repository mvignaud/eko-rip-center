Support now goes through the live support bubble.
Requests opened before this change remain viewable for a while.

## Before you start

- Sign in to the portal.
- Note your request's reference, in the form `TKT-…`.

## Steps

1. Open **Support** in the left-hand menu.
2. Find your request in the list (read-only).
3. Click it to reread the thread.
4. To follow it up, open the live support bubble and write, quoting the `TKT-…` reference. See [Contact live support](rip-cloud-joindre-le-support.md).

   ![Portal Support page with the live support bubble at the bottom right](../../images/cloud-support-bulle.png)

## Good to know

- There is no longer a requests page or a **New request** button (*Nouvelle demande*): everything goes through the bubble.
- These old requests remain readable for 30 days after the switch to live support, then the list is emptied.
- New conversations always start in the bubble; the platform no longer stores requests or discussions.
- If the bubble does not appear, see [Show the live support bubble](rip-cloud-bulle-support-invisible.md).
