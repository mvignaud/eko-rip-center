Remote access is suspended when the plan has been exceeded for more than 14 days.
Work in the workshop was not interrupted.

## Before you start

- Sign in to the portal with the owner account.
- An e-mail warned you of the overage.

## Steps

1. Open **Subscription** (*Abonnement*).
2. Check the machines and sites counted.
3. Subscribe to a suitable plan with **See the plans** (*Voir les offres*).
4. Or remove the extra machines or sites.

## Good to know

- Access comes back as soon as things are put right.
- An explanatory page appears in the browser when access is suspended; the apps receive the response "plan exceeded".
- Use in the workshop is never affected: the server keeps printing and cutting.
