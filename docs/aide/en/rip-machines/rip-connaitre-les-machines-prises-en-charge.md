Each machine in the catalogue has its own article. This article sorts them by family and says what to do for a model that is not listed.

## Before you start

Nothing in particular: this article is a reference.

## Steps

1. Find your machine in this table, then open its article.

   | Family | Machine | The RIP drives |
   |---|---|---|
   | **Printers** | [Epson SureColor SC-S80600](rip-brancher-epson-sc-s80600.md) | printing (direct driver) |
   | | [Roland VersaCAMM VP-300 / VP-540](rip-brancher-roland-versacamm.md) | cutting (print-and-cut machine) |
   | **Cutting plotters** | [Mutoh Kona 1650](rip-brancher-mutoh-kona-1650.md) | cutting, with registration |
   | | [Graphtec FC7000](rip-brancher-graphtec-fc7000.md) | cutting |
   | **Cutting tables** | [none for now](rip-preparer-une-planche-pour-une-table-de-decoupe.md) | |

2. To declare the machine, follow [Add a machine to the RIP](rip-ajouter-une-machine.md).
3. For a model that is not on the list, first try the **Folder** connection (*Dossier*; the RIP drops the files that the machine's software watches) or **IPP**: see [Choose a machine's connection](rip-choisir-la-connexion-d-une-machine.md).
4. To request support for a model, write to [contact@e-ko.rip](mailto:contact@e-ko.rip) with the make, the model and how it is connected.

## Good to know

- Every new machine the RIP supports gets its article in the right family.
- The models in the catalogue are: Epson SC-S80600, Mutoh Kona, Graphtec FC7000 and Roland VersaCAMM VP.
- For what is not yet supported on these machines, see [Know the RIP's current limits](rip-connaitre-les-limites-actuelles-du-rip.md).
