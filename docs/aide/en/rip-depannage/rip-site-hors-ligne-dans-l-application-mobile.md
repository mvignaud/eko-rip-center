In the **Your sites** list (*Vos sites*), an offline site cannot be reached: the workshop server is not linked to the platform.

## Before you start

You have access to the server on site, or someone at the workshop can check it.

## Steps

1. Check on site that the RIP server is switched on.
2. Check that it has Internet access.
3. Reopen the app and tap the site again.

## Good to know

- When the site comes back online, a notification from the platform tells you if the account's notifications are on.
- The platform-side diagnosis is detailed in the article on offline sites.
