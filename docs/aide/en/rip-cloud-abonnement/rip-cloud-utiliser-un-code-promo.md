A promo or partner code can reduce the price or give free months.
You enter it when subscribing, in a single field.

## Before you start

- Have your code at hand.
- The code is optional.

## Steps

1. Open **Subscription** (*Abonnement*), then **See the plans** (*Voir les offres*), choose the plan and click **Choose** (*Choisir*).
2. In the **Promo or partner code** section (*Code promo ou partenaire*), enter the code in the **Code (optional)** field (*Code (facultatif)*).
3. Read the line that appears below: the code is checked straight away and its conditions show (for example "2 months free" or a percentage discount).
4. Continue with the subscription. See [Subscribe to a paid plan](rip-cloud-souscrire-une-offre.md).

## Good to know

- A refused code is flagged immediately: correct it or delete it to continue.
- There is only one field: enter one code at a time, promo code or partner code.
- If in doubt about a code, write to contact@e-ko.rip.
