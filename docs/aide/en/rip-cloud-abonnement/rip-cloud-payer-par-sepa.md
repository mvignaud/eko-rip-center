SEPA direct debit is handled entirely on the page: mandate, SMS code, signature.
The mandate is created in the name of SAS GOLDEN PRINT.

## Before you start

- You have just clicked **Continue to payment** (*Continuer vers le paiement*): see [Subscribe to a paid plan](rip-cloud-souscrire-une-offre.md).
- Have the IBAN, the account holder's name and a mobile phone that receives SMS.
- The mandate applies to the company entered when subscribing. If it changes before you sign, create a new mandate.

## Steps

1. On the **Payment** page (*Paiement*), click **SEPA direct debit** (*Prélèvement SEPA*).
2. Enter the **IBAN**, the **BIC** (optional), the account holder's first and last name, the mobile phone (for the SMS code) and the address.
3. Click **Create the mandate** (*Créer le mandat*). The mandate is displayed on the page.
4. Read it. You can open it as a PDF with **Open the mandate (PDF)** (*Ouvrir le mandat (PDF)*).
5. Click **Receive the code by SMS** (*Recevoir le code par SMS*). The code can take a minute to arrive.
6. Enter the **Code received by SMS** (*Code reçu par SMS*), then the **Signatory's name** (*Nom et prénom du signataire*), typed as the signature.
7. Tick the direct debit authorisation, then click **Sign the mandate** (*Signer le mandat*).

The page states that the mandate is signed and that the subscription is active.

## Good to know

- The signed mandate remains downloadable from the **Subscription** page.
- To use another bank account before signing, click **Use another account** (*Utiliser un autre compte*).
- If the code does not arrive, check the phone number entered, wait a minute, then request it again.
- An e-mail confirms the mandate signature.
- To change bank account later, use **Change payment method** (*Changer de moyen de paiement*). See [Change plan, payment method or cancel](rip-cloud-changer-ou-resilier.md).
