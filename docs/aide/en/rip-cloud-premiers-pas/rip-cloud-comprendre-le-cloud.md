E-KO RIP Cloud gives access to the workshop's RIP server from outside: from home, at a customer's site, on the road.
This article explains the principle before you link your first server.

## Before you start

- The cloud is **optional**. The server keeps working normally in the workshop, with or without it.
- It works **without a VPN** and without changing anything on the Internet router.
- It is **free for a small workshop** (1 site, 1 printer and 1 cutter, with no time limit). Paid plans cover larger workshops.

## Steps

Here is what the cloud allows, and what to do for each use.

1. **Reach the server from a workstation outside the workshop.** Mac, Linux and Windows workstations connect to the server from anywhere. See [Access your RIP server remotely](rip-cloud-acceder-a-distance.md).
2. **Open the administration interface in a browser**, as you would in the workshop. Same article.
3. **Follow production with the mobile app**, away from the workshop. See [Connect an app to the cloud](rip-cloud-connecter-une-app.md).
4. **Get warned when the server stops responding**, by notifications and e-mails. See [Understand cloud notifications](../rip-cloud-compte/rip-cloud-comprendre-les-notifications.md).
5. **Keep an online backup of the server's configuration.** See [Understand online backups](../rip-cloud-sauvegardes/rip-cloud-comprendre-les-sauvegardes.md).

The principle is simple: the **workshop's server itself opens a connection** to the platform (an outgoing connection, like a web page). **No port has to be opened** on the router. Remote workstations and phones go through the platform to reach the server.

To get started, follow in order: [Create an account](rip-cloud-creer-un-compte.md), [Confirm your e-mail address](rip-cloud-confirmer-adresse-email.md), then [Link a RIP server to the cloud](rip-cloud-relier-un-serveur.md).

## Good to know

- Without the cloud, the server can only be reached on the workshop's network.
- Remotely, you sign in either with **your platform account** (the apps, through **Sign in to the cloud**, *Se connecter au cloud*) or with **a RIP server account** (browser, address entered by hand).
- Some functions stay reserved for the workshop. See [Know what never goes through the cloud](rip-cloud-ce-qui-reste-reserve-a-l-atelier.md).
- Plans, their limits and prices are described in [Choose the plan that suits your workshop](../rip-cloud-abonnement/rip-cloud-choisir-une-offre.md).
