Avec l'offre Pro, vous pouvez appliquer la sauvegarde d'un site sur un autre de vos sites.
C'est pratique pour équiper un nouvel atelier avec la configuration d'un atelier existant.

## Avant de commencer

- Le propriétaire du compte doit avoir l'offre **Pro**.
- Les deux sites doivent appartenir au même propriétaire, et vous devez en être propriétaire ou administrateur.
- La restauration remplace la configuration du site cible.

## Étapes

1. Ouvrez **Mes sites**, puis cliquez sur **Sauvegardes** sous le site source.
2. Repérez la version voulue.
3. Sur sa ligne, choisissez le site cible dans la liste déroulante : **Ce site**, ou le nom de l'autre site.
4. Cochez **Remplacer les réglages actuels**.
5. Cliquez sur **Restaurer**, puis confirmez dans la fenêtre qui s'ouvre.

   ![Page Sauvegardes d'un site : chaque version propose Télécharger, la case Remplacer les réglages actuels et le bouton Restaurer](../images/cloud-sauvegardes.png)

## Bon à savoir

- La liste des sites cibles n'apparaît qu'avec l'offre Pro, quand vous avez au moins un autre site.
- Sans l'offre Pro, le message « La restauration vers un autre site est réservée à l'offre Pro, entre sites du même propriétaire » s'affiche.
- Le site cible doit être en ligne pour recevoir l'ordre.
- Un e-mail « Sauvegarde restaurée » prévient le propriétaire et les administrateurs.
