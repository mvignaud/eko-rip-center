Chaque version de sauvegarde se télécharge depuis le portail.
C'est utile avant une restauration ou pour garder une copie hors ligne.

## Avant de commencer

- Le serveur doit être relié au cloud et avoir envoyé au moins une sauvegarde.
- La sauvegarde contient la configuration (machines, réglages, profils ICC…), **ni les travaux ni les comptes**.

## Étapes

1. Ouvrez **Mes sites** sur le portail.
2. Cliquez sur **Sauvegardes** sous le nom du site.
3. Repérez la version voulue : date, motif (**Nocturne**, **Après modification**…) et taille.
4. Cliquez sur **Télécharger** sur sa ligne.

   ![Page Sauvegardes d'un site avec la colonne Télécharger sur chaque version](../images/cloud-sauvegardes.png)

## Bon à savoir

- Le fichier est la même archive que celle de **Système › Sauvegarde** du serveur : vous pouvez la reprendre sur le serveur lui-même. Voir [Sauvegarder la configuration du serveur](../rip-administration/rip-sauvegarder-la-configuration.md).
- Les sauvegardes sont chiffrées et hébergées en France.
- Avant une restauration, en cas de doute, téléchargez d'abord une sauvegarde de l'état actuel. Voir [Restaurer une sauvegarde de la configuration](rip-cloud-restaurer-une-sauvegarde.md).
- Si la liste est vide ou ancienne, voir [Comprendre la durée de conservation et la place des sauvegardes](rip-cloud-duree-de-conservation.md).
