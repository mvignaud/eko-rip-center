Installez E-KO RIP Center.

Un serveur Linux au cœur de l'atelier, puis un client sur chaque poste. Tout est gratuit et open source (AGPL-3.0), publié par GOLDEN PRINT depuis le dépôt GitHub public du projet.

  1. 1. Le serveur sur une machine Ubuntu ou Debian de l'atelier.
  2. 2. Un client sur chaque poste, Mac, Linux ou Windows.
  3. 3. Le premier compte, puis vos machines : voir le guide de démarrage.

Serveur Linux

Ubuntu 24.04 ou Debian récente, 64 bits. Le dépôt APT signé installe le serveur, Ghostscript et le service, puis leurs mises à jour. La dernière commande crée le premier compte administrateur.

$ wget -qO- https://apt.e-ko.fr/rip/eko-rip.gpg | sudo tee /usr/share/keyrings/eko-rip.gpg >/dev/null
$ echo "deb [signed-by=/usr/share/keyrings/eko-rip.gpg] https://apt.e-ko.fr/rip ./" | sudo tee /etc/apt/sources.list.d/eko-rip.list
$ sudo apt update && sudo apt install eko-rip-serveur
$ sudo -u eko-rip env EKO_RIP_DATA=/var/lib/eko-rip eko-rip-serveur utilisateur ajouter admin

Le service écoute sur le port 8640. Mises à jour : sudo apt update && sudo apt upgrade. Matériel conseillé : pré-requis.

Client macOS

macOS 14 ou plus récent, Apple Silicon et Intel. L'application est signée par GOLDEN PRINT (Developer ID) et notarisée par Apple : elle s'ouvre sans avertissement.

Client Linux

Ubuntu et dérivées, GTK 4. Le même dépôt APT signé que le serveur installe le client et ses mises à jour ; le client trouve seul le serveur du réseau local.

$ wget -qO- https://apt.e-ko.fr/rip/installer | sudo sh

Le script ajoute la clé et le dépôt, puis installe le paquet e-ko-rip-center. Vous pouvez le lire avant : apt.e-ko.fr/rip/installer.

Client Windows

Windows 10 et 11, 64 bits. L'installateur n'est pas encore signé : Windows SmartScreen affiche « Windows a protégé votre ordinateur » au premier lancement. Vérifiez l'empreinte ci-dessous, puis cliquez sur Informations complémentaires et Exécuter quand même.
