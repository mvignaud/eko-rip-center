Six façons de brancher une machine

Même sans pilote dédié, le RIP sait souvent déjà parler à votre machine.

Réseau (TCP)

Le flux part en direct vers l'adresse IP de la machine. Pour l'imprimante en pilote direct et les découpeuses en réseau.

Série et USB-série

Pour les découpeuses branchées en USB par un adaptateur série, avec les réglages du port.

Périphérique USB

Pour une machine vue comme imprimante USB par le système.

IPP et CUPS

Le flux passe par une file CUPS sans pilote, ou par une imprimante IPP.

Dossier

Le RIP dépose ses fichiers séparés, un par encre, pour un logiciel tiers qui surveille le dossier. Aucune machine n'est hors jeu.

Renvoi vers un autre RIP

La machine est branchée sur un autre serveur E-KO RIP, dans le même atelier ou sur un autre site.

Une découpeuse qui comprend le HP-GL fonctionne en général en réseau ou en série, avec le bon pas de découpe. Les réglages sont dans les pré-requis et l'aide du logiciel.

Demande de pilote

Votre machine n'est pas dans la liste ?

Décrivez-la : marque, modèle, branchement. Les demandes guident l'ordre des prochains pilotes, et une capture du flux envoyé par le logiciel actuel de la machine accélère beaucoup le travail.

Merci, votre demande est envoyée. Nous vous répondons par e-mail.

La demande n'est pas partie : un champ obligatoire manque, l'adresse e-mail n'est pas valide, ou trop de demandes sont parties de votre connexion. Vérifiez le formulaire, ou écrivez à contact@e-ko.rip.
