    Documentation

    Documentation

    Tout pour installer, utiliser et administrer E-KO RIP Center : serveur, clients Mac, Linux et Windows, application mobile et Cloud.

    E-KO RIP Center est un RIP d'impression grand format libre et gratuit. Un serveur installé sur un PC Linux de l'atelier reçoit les fichiers, calcule les rendus et pilote les imprimantes et les découpeuses. Les postes de travail s'y connectent avec le client Mac, Linux ou Windows ; l'application mobile suit la production ; le Cloud E-KO RIP donne accès à l'atelier depuis l'extérieur.

    #Ce qu'il faut savoir d'abord

    • Tout le travail se fait sur le serveur. Les clients envoient les fichiers et affichent la file ; une fois un fichier envoyé, on peut fermer le client : le rendu et l'impression continuent.
    • Un seul serveur pour tout l'atelier. Tous les postes, Mac, Linux ou Windows, voient la même file et les mêmes machines.
    • Le serveur reste dans l'atelier. Il n'est jamais exposé sur Internet ; pour y accéder de l'extérieur, on passe par le Cloud E-KO RIP, gratuit.
    • Logiciel libre. Le code est public sous licence AGPL-3.0 sur GitHub ; aucune licence à acheter, aucun nombre de postes limité.
