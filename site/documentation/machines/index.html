    Toutes les machines

    Les imprimantes, plotters et tables de découpe pris en charge, comment les ajouter et les brancher.

    Chaque machine du catalogue a sa page : ce que le RIP en fait, comment la brancher, quoi régler sur la machine et dans le RIP, comment vérifier, et les ennuis courants. Le détail des fonctions est dans l'utilisation, l'exploitation du serveur dans l'administration, et les mots dans le glossaire.

    #Ajouter une machine

    Dans le client, ouvrir Administration…, vue Système › Machines, puis Ajouter : choisir le modèle, donner un identifiant et un nom, la laize, la connexion et ses réglages, puis enregistrer. Le lien Aide à côté du modèle ouvre la page de cette machine.

    Pour toutes les machines :

    • Identifiant : minuscules, chiffres et - (epson, kona…). Il nomme le dossier sorties/<machine>/ et sert au renvoi d'un autre RIP : ne pas le changer à la légère.
    • Une sortie à la fois, dans l'ordre de la file de la machine. Une machine qui a encore une sortie à passer ne peut pas être retirée du catalogue.
    • Adresse IP fixe pour toute machine en réseau (voir les exigences du poste).

    #Une machine qui n'est pas dans la liste

    Une machine peut déjà passer par la connexion Dossier (le RIP dépose les fichiers que le logiciel de la machine surveille) ou par IPP. Pour demander la prise en charge d'un modèle, écrire à contact@e-ko.rip avec la marque, le modèle et la façon dont il est branché.
