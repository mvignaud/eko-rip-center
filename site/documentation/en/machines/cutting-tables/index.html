    Cutting tables

    Cutting tables and preparing the sheets meant for them.

    No cutting table is driven directly by the RIP yet. Each supported table will get its own page in this family, like the printers and the plotters.

    #Preparing a sheet for a table

    The RIP already prepares sheets meant for a cutting table:

    • Outline of the whole sheet (NestTrimBox layer) adds a cut rectangle around the placed items, cut last and never printed;
    • Top margin and Bottom margin leave blank space above and below the items.

    Details: sheet (nesting).

    #Asking for a table

    Write to contact@e-ko.rip with the brand, the model and the table's software.
