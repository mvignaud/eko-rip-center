    All machines

    The supported printers, cutting plotters and cutting tables, how to add them and connect them.

    Each machine in the catalogue has its own page: what the RIP does with it, how to connect it, what to set on the machine and in the RIP, how to check, and common trouble. Each feature is described in usage, running the server in administration, and the words in the glossary.

    #Adding a machine

    In the client, open Administration…, System › Machines view (Système › Machines), then Add: choose the model, give an id and a name, the roll width, the connection and its settings, then save. The Help link next to the model opens that machine's page.

    For every machine:

    • Id: lowercase letters, digits and - (epson, kona…). It names the sorties/<machine>/ folder and is used when another RIP forwards to it: do not change it lightly.
    • One output at a time, in the order of the machine's queue. A machine that still has an output to run cannot be removed from the catalogue.
    • Fixed IP address for every network machine (see the server PC requirements).

    #A machine that is not in the list

    A machine can already be reached through the Folder connection (the RIP drops the files that the machine's software watches) or through IPP. To ask for a model to be supported, write to contact@e-ko.rip with the brand, the model and how it is connected.
