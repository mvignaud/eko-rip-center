    Prise en main

    Comprendre comment s'articulent le serveur, les clients, l'application mobile et le Cloud, puis installer un atelier en cinq étapes.

    Cette page présente les pièces d'E-KO RIP Center et l'ordre dans lequel les installer. Compter une heure pour un atelier simple : un serveur, un ou deux postes, une imprimante et une découpeuse.

    #Les pièces du RIP

    PièceOùRôle
    Serveur RIPun PC Linux de l'atelier, allumé en permanencereçoit les fichiers, calcule les rendus, tient la file d'attente, pilote les machines
    Client E-KO RIP Centerchaque poste de travail (Mac, Linux, Windows)envoie les fichiers, suit les travaux, lance les impressions et les découpes
    Application mobiletéléphone iOS ou Androidsuit la file et les machines, reçoit les alertes (cartouche vide, machine injoignable…)
    Cloud E-KO RIPservice en ligne, platform.e-ko.ripdonne accès au serveur depuis l'extérieur, sans VPN ni port ouvert
    Interface d'administrationdans le client (Administration…) ou par le Cloud dans un navigateurréglages des machines, supports, couleur, comptes, sauvegarde

    Un navigateur ouvert sur l'adresse du serveur dans l'atelier n'affiche qu'une page d'état (version, machines, adresse à saisir dans le client) : l'interface complète est réservée aux clients.

    #Installer un atelier en cinq étapes

    #1. Préparer le serveur

    Choisir un PC 64 bits (x86) qui restera allumé, de préférence avec un SSD réservé aux données, branché en câble et sur onduleur. Lui donner une adresse IP fixe sur le routeur. Détail : choisir le poste serveur.

    #2. Installer le serveur

    Sur Ubuntu 24.04 ou 26.04 LTS, ajouter le dépôt E-KO puis installer le paquet eko-rip-serveur. Le service démarre seul et redémarre avec le PC. Détail : installer par le dépôt APT.

    #3. Créer les comptes

    Tant qu'aucun compte n'existe, n'importe quel poste du réseau peut tout faire et l'écran le signale en rouge. Créer au moins un compte administrateur, puis un compte opérateur par personne. Détail : comptes et rôles.

    #4. Installer les clients

    Sur chaque poste, installer le client puis choisir le serveur dans la liste Serveurs trouvés sur le réseau. Détail : installer les clients.

    #5. Déclarer les machines

    Dans le client, menu Administration…, vue Système › Machines : ajouter chaque imprimante et chaque découpeuse, sa connexion (réseau, USB, dossier) et ses supports. Chaque modèle a sa page dans la rubrique Machines.

    Astuce

    Avant la première vraie production, envoyer un petit PDF d'essai, vérifier son aperçu et ses plaques dans l'inspecteur, puis l'imprimer sur une chute.

    #Et ensuite

    • Envoyer un premier travail et apprendre la file.
    • Installer l'application mobile pour être prévenu d'une panne.
    • Rattacher le serveur au Cloud E-KO RIP pour y accéder de l'extérieur.
    • Programmer une sauvegarde de la configuration.

    #Ce dont le serveur a besoin sur le réseau

    SensPortPour
    Postes → serveurTCP 8640clients, application mobile dans l'atelier, renvoi entre RIP
    Postes ↔ serveurUDP 5353 (mDNS)découverte automatique du serveur par les clients
    Postes → serveurTCP 445dossiers surveillés partagés (Samba), si on les partage
    Serveur → imprimantesTCP 9100, 631 (IPP), UDP 161 (SNMP)envoi des travaux, niveaux d'encre, média chargé
    Serveur → InternetTCP 443 (HTTPS, sortant)mises à jour, Cloud E-KO RIP, ERP

    Attention

    Ne jamais ouvrir le port 8640 sur Internet : la connexion n'est pas chiffrée. Pour travailler à distance, utiliser le Cloud E-KO RIP.
