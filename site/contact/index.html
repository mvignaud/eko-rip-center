Parlons de votre atelier.

Une question, une démonstration, une machine à brancher, un partenariat ? Écrivez-nous : c'est l'équipe qui développe le RIP qui vous répond, par e-mail.

Merci, votre message est envoyé. Nous vous répondons par e-mail, en général sous un jour ouvré.

Le message n'est pas parti : un champ obligatoire manque, l'adresse e-mail n'est pas valide, ou trop de messages sont partis de votre connexion. Vérifiez le formulaire, ou écrivez à contact@e-ko.rip.
