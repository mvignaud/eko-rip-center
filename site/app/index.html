Application mobile

L'atelier dans la poche.

E-KO RIP pour iPhone et Android suit le serveur RIP de votre atelier : la file d'impression, l'état des machines, les niveaux d'encre et les alertes, avec une notification dès qu'une machine s'arrête en erreur.

App Store et Google Play : bientôt disponible

Assistance

Questions fréquentes

Comment me connecter ?

Saisissez l'adresse de votre serveur RIP et votre compte du serveur (celui que vous utilisez dans le client de bureau). À l'atelier, l'adresse locale suffit ; de l'extérieur, utilisez l'adresse de votre site sur le Cloud E-KO RIP (https://<site>.platform.e-ko.rip).

Je ne reçois pas les notifications

Vérifiez qu'elles sont activées dans l'application et dans les réglages du téléphone, puis que votre serveur RIP est à jour. Se déconnecter et se reconnecter renouvelle l'inscription de l'appareil auprès du serveur.

Je veux juste essayer

Le mode démo, sur l'écran de connexion, montre l'application avec des données fictives, sans connexion ni serveur.

Et mes données ?

L'application parle uniquement à votre serveur RIP. L'éditeur ne reçoit rien : ni compte, ni publicité, ni mesure d'audience. Le détail est dans la politique de confidentialité.

Mode d'emploi complet dans la documentation de l'application. Une autre question, un problème ? Écrivez à contact@e-ko.rip.
